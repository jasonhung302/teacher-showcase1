如何還原

  1. 先停止網站（在執行網站的視窗按 Ctrl + C，或 systemctl stop teacher-showcase）。
  2. 在專案資料夾執行：python -m flask --app wsgi restore-backup 備份檔路徑.zip
  3. 系統會先把目前資料另存為 before-restore-….zip，再還原，最後重新啟動網站即可。

每日自動備份：可將 python -m flask --app wsgi backup 加入排程（Windows「工作排程器」或 Linux cron）。
